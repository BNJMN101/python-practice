## 📂 Projects

### 🎓 Student Grade Tracker CLI

A command-line application for managing a student's courses and grades.

The program currently allows the user to:

* Add courses
* View enrolled courses
* Add or update grades
* View student results
* Calculate the average grade
* Exit the application

The project uses:

* Functions
* `while` loops
* `if / elif / else`
* Sets
* Dictionaries
* Dictionary methods such as `.items()` and `.values()`
* `sum()` and `len()`
* User input
* Formatted strings

### 💻 Example

```text
================================
Student Grade Tracker CLI
================================
1. Add Course
2. View Courses
3. Add Grade
4. View Results
5. Calculate Average
6. Exit

Choose an option (1-6): 5
Average Grade 81.50
```

## 🧠 Learning Through Mistakes

This repository isn't meant to contain perfect code.

It's a record of my learning process.

While building these projects, I intentionally work through errors, bugs, confusing concepts, and refactoring instead of simply copying solutions.

For example, while building the Student Grade Tracker, I encountered problems involving:

* Syntax errors
* Sets vs. dictionaries
* Dictionary key/value access
* `KeyError`
* `UnboundLocalError`
* Loop behavior
* Function structure
* Program control flow

Each mistake helped me understand the underlying Python concepts better.

My long-term goal is to become a strong software developer and eventually work as a full-stack developer.
